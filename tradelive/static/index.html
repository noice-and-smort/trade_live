How to use TradeLive

1. Every day

  • Switch on the computer. TradeLive opens by itself (if Start automatically is ticked).
  • At 8:35 Zerodha's login page opens in the browser. Log in there (Zerodha requires this once a day). You are sent back and TradeLive reopens your watchlist and last contract by itself.
  • Missed the 8:35 page? Click Connect broker → Connect any time.
  • Started late or the computer slept? No problem: Zerodha's history includes OI, so the whole day is filled in, including OI.

2. Choosing what to watch

  • Source: Zerodha (live) for real data, Replay to play a saved Excel file (practice or after hours; ▶ Play restarts it).
  • Symbol: type an index or F&O stock (NIFTY, BANKNIFTY, RELIANCE…). Expiry and Strike fill in; the strike starts at the one nearest the current price.
  • CE / PE / FUT / Cash: call, put, futures, or the share itself. Cash has no OI, so the OI columns and signals stay empty for it.
  • Click Watch. The badge shows LIVE or REPLAY. Weekly contracts move to the next expiry automatically after they expire.

3. Watchlist (many contracts at once)

  • Click ☆ Add to watchlist next to the contract name. Up to 20 contracts appear in the Watchlist at the top and stay live all day.
  • Each row: price, % change, above/below VWAP, PSAR, latest signal (and how many bars in a row), net OI flow, biggest volume.
  • Click a row to open its full table below. ✕ removes it. Sort puts the most active on top. Clear all empties the watchlist.
  • Switching between contracts never loses rows: reopening one reloads the whole day from Zerodha, including OI.
  • ⧉ New window opens another TradeLive window. Each window can show a different contract (side by side); they share the one Zerodha login, the watchlist and the settings.

4. The cards and the signal summary

  • Cards (latest bar): Net OI flow, Price vs VWAP, PSAR, Latest signal (and streak), and how long ago the biggest volume was.
  • Signal summary (below the cards), over the counted rows: for each of LB SC SB LU the number of bars, the total OI change and the total volume.
  • The bar above it compares price-up bars (LB + SC) with price-down bars (SB + LU) by share of OI moved.
  • Net OI flow = (LB + SC) − (SB + LU) OI change – exactly your P2 cell. Note: in this formula long unwinding adds and short covering subtracts.

6. Settings in the top bar

  • Candle 1m / 3m / 5m.
  • Rows to count: how many recent rows are used for Net flow, the signal summary and the highlights (All, 5, 10… or Custom).
  • Top volumes: how many of the biggest volumes to highlight (Off, 1, 3, 5, 10).
  • Sound alerts: a beep when a signal repeats 3 bars in a row or price crosses VWAP (for every watched contract).
  • Start automatically: open TradeLive when the computer starts. It always starts the copy you opened last (after an update, open the new one once), never an old or deleted one.
  • Show chart: candles, VWAP, PSAR dots, volume and OI.
  • Download Excel: your usual sheet with the same formulas and colours, plus the signal summary (columns S–V).

7. Zerodha one-time setup

  • On developers.kite.trade create a Kite Connect app (₹500/month, credited back in months with ₹2,000+ brokerage).
  • Set its Redirect URL to exactly http://127.0.0.1:8765/kite/callback.
  • In TradeLive: Source: Zerodha (live) → Connect broker → paste the API key (short) and API secret (long), keep Remember ticked → Connect → log in on Zerodha's page.

8. If something looks wrong

  • Blue note at the top = information (e.g. market closed, login page opened). Red note = a problem; TradeLive retries by itself.
  • “Invalid api_key” on Zerodha's page: the Kite Connect app isn't active/paid yet, or the key was copied wrongly – copy it again from developers.kite.trade.
  • After the Zerodha login nothing happens: probably two TradeLive copies are running. Task Manager → end every TradeLive.exe, start TradeLive once, click Connect broker again.
  • OI columns empty: normal for Cash (shares have no OI) and before 9:15.
  • Screen looks old after an update: close every TradeLive (Task Manager → TradeLive.exe → End task) and start again. The version is shown at the bottom right.
  • For help, send the file tradelive.log (next to TradeLive.exe). Never send passwords, the API secret or codes.
